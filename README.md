# Arena Cartada

Site com cinco jogos que rodam direto no navegador, feito em HTML, CSS e JavaScript puro, sem nenhuma biblioteca. Foi um trabalho em grupo da faculdade, no curso de Sistemas de Informação da Unilasalle-RJ.

**Jogue aqui:** https://flourishing-quokka-6f2067.netlify.app/

## Os jogos

| Jogo | Como funciona |
|---|---|
| Blackjack | O 21 contra a banca: pedir carta, parar e tentar chegar perto de 21 sem passar. |
| Digitação Rápida | Copiar o texto da tela o mais rápido possível; o jogo mede velocidade e precisão. |
| Haxball | Futebol em campo visto de cima, com física simples de bola e chute. |
| Termo | Adivinhar uma palavra de 5 letras em poucas tentativas, com dicas de cor a cada letra. |
| Vença o Baralho | Escolher uma das 9 cartas da mesa e adivinhar se a próxima do monte será maior ou menor; cada erro custa uma das 9 vidas. |

## O que o projeto usa

- Uma página inicial que leva a cada jogo, e cada jogo com seus próprios arquivos `.html`, `.css` e `.js`
- Manipulação do DOM e eventos de teclado e mouse
- Lógica de jogo em JavaScript: baralho, pontuação, tempo e verificação de palavras
- Layout responsivo com CSS

## Como rodar

Não precisa instalar nada: basta baixar o repositório e abrir o `index.html` no navegador.
